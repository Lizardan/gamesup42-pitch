# Журнал решений

## 2026-11-25 — FrostSpace в анкету, BARAKI как вторая демка

Основная игра заявки — FrostSpace: единственный проект с готовой браузерной сборкой и 25–30 минутами контента, весь арт собственный. BARAKI идёт второй играбельной демкой и разделом инженерии, Woodberry — разделом дизайна и арта.

**Почему не BARAKI основной:** 30 минут требуют бота и стабильного WebGL, это 3–5 недель. Плюс весь играбельный арт — временные модели Warcraft III Reforged, чужие права.

## 2026-11-25 — BARAKI без бота

В веб-демо нет AI-противника: матч запускается на два слота, второй занимает локальная «статуя». Волны выходят и идут по линиям — этого достаточно, чтобы пощупать цикл. Сетевые кнопки выключены и серые. Это честно написано на странице.

## 2026-11-25 — BARAKI WebGL опубликован

Сборка влезла в лимит GitHub Pages: 98,4 МБ данных. Что сделано: включён stripping движка, выключена поддержка исключений, командные текстуры сжаты для WebGL (512 px, ASTC 8×8), лаунчер на WebGL пропускается — игра открывается сразу в главном меню. Лобби, локальное заполнение слотов, старт матча и волны работают; выбор расы и бонусов автоматический, pick-оверлеи скрываются клинером после загрузки сцены. Сборка едет release-ассетом `webgl-demo/baraki-webgl.zip`, сайт забирает её при деплое.

## 2026-11-25 — Hero: вариант A «Смена»

Показаны три варианта (A/B/C). Выбран A: полноэкранный кадр, крупный заголовок, HUD-сетка и кольцо сканера. Меню-язык из варианта B перенесён в навигацию и секции.

## 2026-11-25 — Сборки не в git

FrostSpace — 32 МБ, BARAKI — потенциально 100+ МБ. Вместо коммита бинарников workflow скачивает актуальные сборки в `site/play/` перед публикацией. Исходники остаются в игровых репозиториях.

## 2026-11-25 — Один репозиторий на всё

`Lizardan/gamesup42-pitch`: лендинг, обе демки, документация. Один адрес для анкеты и один для игры.

## 2026-11-25 — Видео

Трейлер 60–90 с + прохождение главами. Запись через Playwright, монтаж через ffmpeg-static. Длинное видео целиком не льём из-за лимита Pages 100 МБ на файл.
